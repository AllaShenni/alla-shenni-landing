# Сайт-визитка Аллы Шенни

Сайт куратора студентов, модератора вебинаров и технического специалиста онлайн-школ.

**Открыть сайт:** https://allashenni.vercel.app

## Что на сайте

- Разделы: обо мне, услуги, опыт, вопросы и ответы, контакты
- Форма обратной связи (Formspree)
- Связь в Telegram через бота-ассистента

## Стек

Next.js, React, TypeScript, Tailwind CSS. Хостинг: Vercel.

Сделан в Claude Code через вайбкодинг.

## Запуск на компьютере

```bash
npm install
npm run dev
```

Сайт откроется по адресу http://localhost:3000
